## Git Workflow

### Git Status
I used git status to check which files had been changed in my local repository. Git showed that my ServerStudent.MD file had been modified and was not yet staged for a commit. It also identified other files that had been deleted from my local copy.
Command:
git status
### Git Add
I used git add to stage my ServerStudent.MD file so that Git would include it in my next commit. I specified the filename instead of staging every file because I only wanted to commit my assignment changes.
Command:
git add ServerStudent.MD
### Git Commit
I used git commit to save my staged changes to the local repository. I included a message explaining what I updated.
Command: 
git commit -m "Update ServerStudent documentation"
### Git Push
I used git push to upload my committed changes from my local main branch to my GitHub repository.
Command: 
git push origin main
